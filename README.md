🚀 Shahriar Ibne Alam Mahee — Personal Portfolio Website

An interactive, dark-cyberpunk portfolio website designed and developed by Shahriar Ibne Alam Mahee — Computer Science & Engineering undergraduate at the International Islamic University Chittagong (IIUC), Competitive Programmer, C++/Java Developer, and Visual Photographer.

🌐 Live Website

🔗 Visit Live Site: https://maheecse.github.io/portfolio/

✨ Key Features

🌌 Dynamic Particle & Meteor Canvas: Real-time interactive canvas background rendering moving node particles, vector connectors, and shooting meteors.

🎴 3D Interactive Tilt Cards: Responsive card components featuring mouse tracking, perspective rotation, dynamic glare highlights, and sound effects.

⚡ Gemini AI Code Analyzer: Embedded AI tool to evaluate C++/Java code snippets for Big-O time and space complexity, memory bounds, and STL optimizations.

💬 Interactive AI Twin Chatbot: AI assistant powered by Google Gemini to answer visitor questions about studies, competitive programming, and photography.

🖥️ Interactive Command Terminal: A functional interactive terminal shell supporting built-in system commands (whoami, cat, ls) and direct AI queries.

📸 Photography Showcase & Lightbox: Filterable gallery featuring street, nature, portrait, and architectural shots with an immersive image lightbox modal.

🔊 UI Audio FX Engine: Web Audio API sound synthesis for interactive click and hover feedback with a global toggle.

🛠️ Tech Stack & Libraries

Frontend Core: HTML5, CSS3, JavaScript (ES6+)

UI Library: React 18 (Browser UMD Runtime via Babel Standalone)

Styling: Tailwind CSS (CDN Configuration with custom glow & shimmer keyframes)

Fonts: Plus Jakarta Sans, Fira Code, Space Grotesk

AI Integration: Google Gemini 3 Flash API

Icons & Graphics: HTML5 Canvas API, SVG Icons

💻 How to Run Locally

Option 1: Live Server (Recommended)

Clone this repository to your local computer:

git clone https://github.com/maheecse/portfolio.git
cd portfolio


Open the project folder in Visual Studio Code.

Install the Live Server extension in VS Code.

Right-click on index.html and select "Open with Live Server".

Option 2: Direct Browser Launch

Simply double-click on index.html to open it in modern web browsers (Google Chrome, Microsoft Edge, Brave, Firefox, etc.).
